# World Atlas

Offline world atlas for Android (Java, no AndroidX, no libraries, no internet permission).
Package: `com.blackfalcon.worldatlas`. By: Black Falcon

## What it has
- **Map**: pan, pinch zoom, double-tap zoom, four map themes (night, day, terrain, paper), scale bar, graticule with degrees,
  countries, capitals, cities and regions appear as you zoom in (level of detail), tap a marker for a card, long press for
  coordinates and the nearest known place, "my location" button (optional GPS, works offline).
- **Search** (offline): countries, 5,046 states/provinces/regions of every country (ISO 3166-2, all levels) and 886 cities.
  Type English, Urdu or Arabic. Recently opened items.
- **Countries**: all 250 ISO countries and territories; sort by name, population or area; filter by continent or territories.
- **Detail pages**: flag, names in English/Urdu/Arabic, capital, continent, population, area, density, currency, calling code,
  ISO codes, capital coordinates, distance from you, all states/provinces/regions (tap for the next level), cities,
  nearby cities, **Show on map**, **Wikipedia** link (opens your browser), copy details.
- **Quiz**: guess the flag, capital of a country, country of a capital, currency of a country (10 questions, best scores saved).
- **Settings**: language (English default, Urdu, Arabic), dark/light app theme, map theme, kilometers/miles.

## Build
1. Upload the contents of this folder to a GitHub repository.
2. GitHub Actions ("Build APK") runs on every push. Download `WorldAtlas-APK` from the run's Artifacts.

## Privacy
No internet permission. Location is optional, used only on the phone. Only the Wikipedia button opens the browser (internet), only when you tap it.

## Honest limits
- **Coastlines are simplified** (about 1,100 points, hand-drawn) and the built-in map has **no country borders**.
  To get real borders, see "Borders" below.
- **Map points for regions**: all 5,046 regions are searchable by name, but only about 730 have a stored map point
  (all states/provinces of Pakistan, India, USA, China, Canada, Australia, Brazil, Germany, Mexico, Indonesia, Iran, Afghanistan,
  Saudi Arabia, Nigeria, South Africa, Argentina, Italy, Spain, France, Bangladesh, Nepal, Sri Lanka, Myanmar, Egypt, UK nations,
  Kazakhstan, Iraq, UAE, plus regions that share a name with a stored city). For the others the page opens with the country shown.
  Region positions are approximate centers, not borders.
- **Cities**: 886 places (the larger cities of each country, all capitals, plus representative places from the tz database).
  This is not a full list of every town. City and region names are English except where Urdu/Arabic names exist (about 380 cities).
- **Populations, areas and city positions** were compiled by hand and rounded (about 2023/24). They are approximate.
- Search is by name only (no addresses). Flags are emoji and depend on the phone's font.
- Not compiled or tested on a device by the author; the calculations, search and data loader were tested on a computer.

## Borders (optional upgrade, needs a computer with internet once)
1. Download Natural Earth "Admin 0 - Countries" 1:110m as GeoJSON (public domain), e.g. `ne_110m_admin_0_countries.geojson`.
2. `python3 tools/make_world.py ne_110m_admin_0_countries.geojson app/src/main/assets/world.txt 0.02`
3. Commit and push. The map then draws borders, highlights the tapped country and names the country under a long press.

## Data sources and rebuilding the data
`app/src/main/assets/*.tsv` are generated by `tools/build_data.py` from `tools/data_src/*.txt` (hand-compiled capitals, cities,
region centers, Urdu/Arabic names) plus ISO 3166 names (iso-codes project, LGPL-2.1+), Unicode CLDR via Babel (country, currency
and city names in Urdu/Arabic; Unicode License) and the IANA tz database (public domain). To add more region centers or cities,
add lines to `tools/data_src` and run `python3 tools/build_data.py tools/data_src app/src/main/assets` on Linux with `babel` and
`iso-codes` installed (the script reads `/usr/share/iso-codes` and `/usr/share/zoneinfo`).
